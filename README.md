# Laravel Nightwatch VitoDeploy Plugin

This plugin enables Laravel Nightwatch monitoring for Laravel sites deployed with VitoDeploy.

## Features
- Validates Nightwatch installation
- Prompts for token and port
- Appends env variables safely
- Creates per-site worker

## Requirements
- VitoDeploy >= 3.16
- Laravel app
- `composer require laravel/nightwatch`

## Usage
Enable the feature on a Laravel site and provide the token and port.
